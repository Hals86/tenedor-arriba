## 1. DESCRIPTION

 Welcome to tenedores-arriba app an expo based mobile app created for learning purposes and simulate , where users can add restaurants to the app, rate and share their experiences so new users customers can decide to visit or not based on others reviews.

## 2. INSTALLATION

System Dependencies.

`brew install node` => install node.js on the computer (v23.7.0)
`brew install yarn` => install yarn on the computer (1.22.22)

Create New Project.

`npx create-expo-app@latest --template` Create new project {default, blank, blank typescript,nav typescript,etc}>>> *blank selected in this pname of the projectroject*

Project Dependencies.
`
`cd tenedores arriba`
`yarn install`

Running Locally 

 `yarn start` initializes the project
 `yarn expo start --tunnel` initializes the project(tunnel used for avoiding network errors )
 yarn expo start --clear (clear metro cache)

 ## 3. DEPENDENCIES

 **yarn add @rneui/themed @rneui/base** => react native elements UI KIT components
 **yarn add react-native-vector-icons** =>icons
 **yarn add @react-navigation/native** => navigate in react native between  screens and share data between them.
 **yarn add @react-navigation/native-stack** It's a stack navigator that uses the native navigation primitives (UINavigationController on iOS and Fragment on Android) for navigation
 **yarn add react-native-screens react-native-safe-area-context** => Required dependencies for react-navigation to handle native screen containers and safe area insets
 **yarn add @react-navigation/bottom-tabs** bottom nav bar for changing screens
